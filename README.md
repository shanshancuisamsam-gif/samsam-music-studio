# Samsam Music Studio

Samsam 老师的流行声乐课堂网页。以白裙数字人形象展示课程，包含七个学习模块、中文语音讲解和呼吸练习。

## 在电脑上查看

1. 在 GitHub 仓库页面点击 **Code → Download ZIP**。
2. 解压 ZIP，保持所有文件在同一个文件夹里。
3. 双击 `index.html`，使用 Chrome、Edge 或 Safari 打开。

页面、图片、课程切换和呼吸练习不需要网站服务器。中文朗读使用浏览器或操作系统的语音服务，是否可用及是否需要网络取决于设备；页面中也有完整讲解文字。

这是静态数字人形象与课程交互体验版，尚未包含视频口型动画或老师原声。

## 用 Codex 继续修改

在电脑端 Codex 中打开解压后的项目文件夹，并选择 **本机 / This computer / Local**。让 Codex 直接修改文件，然后刷新浏览器查看结果。

当前仓库只同步源码，没有配置自动部署。之前的 `chatgpt.site` 在线地址与本仓库的本地预览分开；浏览器打开 GitHub 文件页面时显示的是源码，下载后打开 `index.html` 才是网页。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构、导航与课堂展示 |
| `style.css` | 颜色、布局、手机适配与动画 |
| `app.js` | 七节课程、语音讲解和呼吸练习 |
| `teacher.webp` | Samsam 数字人老师形象 |

不需要安装依赖，也没有构建步骤。
